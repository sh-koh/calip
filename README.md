# 🌐 Calip

Calip is a small CLI tool to deal with networking stuff such as
ip addresses' conversion in binary format, subnet
calculation, etc.

## 📔 Features
- Convert each byte of an IPv4 into binary
- More soon...

## 🔨 Building
#### `nix`:
```bash
$ nix build .#
```

#### `cabal`:
```bash
$ cabal build
```

#### `stack`:
```bash
$ stack build
```
